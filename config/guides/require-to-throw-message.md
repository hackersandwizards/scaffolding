# Calling `toThrow()` without an argument passes on any thrown error, including an unintended bug.

Pass the message, regex, or specific error class callers rely on so another error fails. For library errors such as schema validators, assert the exported class. To check which input failed, call the library's result-returning form and assert the structured issue path and code.

No fix: `toThrow(Error)`, `toThrow("")`, or a broad pattern such as `/./`.
